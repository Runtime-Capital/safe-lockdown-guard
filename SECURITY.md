# Security Policy

## Supported version

Security fixes are prepared for the latest `v1.0.x` release line. Pre-release
commits and historical internal tags are not supported releases.

## Reporting a vulnerability

Email `contact@runtime.capital` with the subject `safe-lockdown security
report`. Do not open a public issue or disclose the report publicly until a
coordinated disclosure date has been agreed.

Please include:

- the affected commit, tag, contract, and function;
- impact and realistic preconditions;
- reproducible steps or a minimal proof of concept;
- any suggested mitigation;
- a safe way to contact you for follow-up.

We will acknowledge receipt, validate the report, and coordinate remediation
and disclosure. Never include live private keys, seed phrases, credentials, or
production secrets in a report.
