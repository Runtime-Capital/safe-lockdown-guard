safe-lockdown WebAuthn fixture recorder

Captures the exact browser/passkey assertion shape that `WebAuthnVerifier` must accept. The output is public test material: P-256 public key, challenge, authenticatorData, clientDataJSON, DER-decoded r/s, and the flat ABI signature bytes.

Device / browser metadata

Run this page on each target environment: Chrome desktop, Chrome Android, Safari iOS, Safari macOS, YubiKey/FIDO2 key where relevant. Use `localhost` on desktop; do not use `127.0.0.1`, because WebAuthn rejects IP addresses as RP domains. Mobile devices need HTTPS, for example a Cloudflare tunnel to localhost. Keep the origin stable across registration and assertion. 
No passkey registered in this page yet.

Fixture JSON

Save as `test/fixtures/webauthn/<label>.json`, then run `node scripts/webauthn-fixture-to-sol.js` and `forge test --match-contract WebAuthnCapturedFixtures`.
